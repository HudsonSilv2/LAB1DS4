# LAB1DS4 — Projeto de teste Git/GitLab

CLI simples de lista de tarefas usado para praticar **boas práticas de Git** no GitLab.

## Como executar

```bash
python3 src/todo.py add "Estudar Git"
python3 src/todo.py list
python3 src/todo.py done 1
```

## Convenção de branches

- `main` — código estável
- `feat/<assunto>` — novos recursos
- `fix/<assunto>` — correções
- `docs/<assunto>` — documentação
